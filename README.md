# Olivas Flores Abogados — Sitio Web Institucional

Landing page institucional para la firma jurídica **Olivas Flores Abogados**, desarrollada con un enfoque arquitectónico, minimalista y orientado a la conversión calificada.

## 🛠️ Tecnologías utilizadas
- **HTML5** semántico y SEO optimizado.
- **Tailwind CSS v3** (vía CDN) + Lucide Icons.
- **JavaScript Vanilla** (Interacciones, validación de formularios, modales de lectura, menú móvil auto-desplegable y Libro de Reclamaciones).
- **Google Fonts** (Cormorant Garamond & Plus Jakarta Sans).

## 🚀 Despliegue en GitHub Pages
1. Sube este repositorio a GitHub.
2. Ve a **Settings** > **Pages**.
3. En **Source**, selecciona la rama `main` (o `master`) y la carpeta `/ (root)`.
4. Guarda los cambios. Tu sitio estará en línea en un par de minutos.

## 📝 Configuración pendiente para producción
- **WhatsApp:** Cambiar el número de teléfono en la variable dentro del enlace de WhatsApp en `index.html`.
- **Formulario de contacto:** Reemplazar el handler del formulario con el endpoint definitivo (ej. Formspree, EmailJS o backend propio).
- **Dominio:** Configurar los registros DNS tipo A / CNAME si se vincula un dominio `.pe` o `.com`.
